# # Random Quote Generator

![Flutter](https://img.shields.io/badge/Flutter-3.47-blue)
![Dart](https://img.shields.io/badge/Dart-3.x-blue)
![Platform](https://img.shields.io/badge/Platform-Android-green)

**Random Quote Generator** is a simple and clean mobile application built using **Flutter** and **Dart**. It displays random inspirational quotes with their authors and allows users to generate a different quote instantly with the tap of a button.

The application works completely offline and provides a minimal, responsive interface designed for a smooth mobile experience.

> **Note:** This is my first Flutter and Dart application. I built this project while learning Flutter to understand the basics of mobile app development, UI design, state management, app icons, splash screens, and Android APK builds.

---

## # Features

* Displays a random quote when the app starts
* Generates a different quote using the **New Quote** button
* Displays the author name for each quote
* Prevents the same quote from appearing twice consecutively
* Smooth quote transition animations
* Clean and minimal user interface
* Custom application icon
* Custom splash screen
* Fully offline functionality
* Responsive Android layout
* Fast and lightweight
* Installable Android APK
